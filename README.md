# 🎓 Resumo Integrado: Grade Curricular de Tecnologia

Este documento apresenta uma visão consolidada e sinergia entre as quatro disciplinas fundamentais para o desenvolvimento de software e sistemas integrados.

---

## 📋 1. Engenharia de Requisitos
*   **Foco Principal:** Elicitação, análise, especificação e validação das reais necessidades do cliente.
*   **Pilares Técnicos:**
    *   **Requisitos Funcionais:** O que o sistema deve fazer (ações e comportamentos).
    *   **Requisitos Não Funcionais:** Como o sistema deve operar (desempenho, segurança e restrições).
*   **Ferramentas e Métodos:** Técnicas de elicitação (Entrevistas, Brainstorm, Prototipagem) e documentação técnica por meio de diagramas UML (Casos de Uso) e relatórios estruturados (SRS).

---

## 🖥️ 2. Sistemas Operacionais (SO)
*   **Foco Principal:** Gerenciamento dos recursos de hardware (CPU, RAM, Dispositivos de E/S) e interface com as aplicações.
*   **Ecossistemas Estudados:**
    *   **Windows:** Arquitetura de kernel híbrido, uso comercial predominante, foco em APIs nativas (Win32) e sistema de arquivos NTFS.
    *   **Linux:** Kernel monolítico de código aberto, estrutura unificada de diretórios (`/`), forte controle de permissões e uso massivo via linha de comando (Bash/CLI).

---

## 🐍 3. Lógica de Programação
*   **Foco Principal:** Desenvolvimento do raciocínio algorítmico e resolução estruturada de problemas matemáticos e computacionais.
*   **Linguagem Base (Python):** Sintaxe limpa, alto nível, tipagem dinâmica e o uso obrigatório de indentação para delimitar blocos de controle.
*   **Estruturas Fundamentais:** Manipulação de variáveis, operadores relacionais/lógicos, desvios condicionais (`if/elif/else`) e laços de repetição (`for/while`).

---

## 🌐 4. Arquitetura de IoT (Internet das Coisas)
*   **Foco Principal:** Conexão de objetos físicos ao ecossistema digital por meio de redes estruturadas em camadas.
*   **Hardware e Conectividade:** Uso de microcontroladores (ESP32, Arduino) conectados a sensores e atuadores, comunicando-se por protocolos leves e otimizados (MQTT, CoAP, LoRaWAN).
*   **Processamento Distribuído:** Equilíbrio entre **Edge Computing** (processamento rápido e local na borda) e **Cloud Computing** (análise de dados massiva na nuvem).
