# 🖥️ Sistemas Operacionais: Fundamentos, Windows e Linux

## 📑 1. Conteúdo de Aula
*   **Conceito:** O sistema operacional como gerente de recursos de hardware e intermediário entre usuário e máquina.
*   **Funções Principais:**
    *   Gerenciamento de Processos (CPU).
    *   Gerenciamento de Memória (RAM e Virtual).
    *   Gerenciamento de Arquivos (Diretórios e Armazenamento).
    *   Gerenciamento de Dispositivos (E/S e Drivers).
*   **Arquitetura:** Diferenças fundamentais entre sistemas monolíticos, microkernel e híbridos.

---

## 🪟 2. Sistema Operacional Windows
*   **Histórico e Evolução:** Transição da interface MS-DOS para a arquitetura moderna baseada em Windows NT.
*   **Arquitetura:** Modelo de kernel híbrido, dividindo o sistema entre Modo Usuário e Modo Kernel.
*   **Subsistemas:** Uso de APIs nativas (Win32/Win64) para execução de aplicações e compatibilidade de software.
*   **Sistema de Arquivos:** Padrão NTFS (com suporte a permissões avançadas e journaling) e o legado FAT32/exFAT.
*   **Gerenciamento:** Ferramentas nativas como Registro do Windows, Gerenciador de Tarefas e Prompt de Comando (CMD/PowerShell).

---

## 🐧 3. Sistema Operacional Linux
*   **Histórico e Filosofia:** Criado por Linus Torvalds baseado no Unix; software livre de código aberto (Open Source).
*   **Arquitetura:** Modelo de kernel monolítico, onde drivers e sistemas de arquivos rodam diretamente no espaço do kernel.
*   **Distribuições (Distros):** Variedade de ecossistemas adaptados para diferentes nichos (ex: Ubuntu, Debian, Fedora, Arch, CentOS).
*   **Sistema de Arquivos:** Estrutura em árvore única unificada (`/`) usando padrões modernos como EXT4, XFS ou Btrfs.
*   **Interface de Linha de Comando (CLI):** Importância do terminal (Shell/Bash) para automação e administração via comandos básicos (`ls`, `cd`, `chmod`, `ps`).
*   **Permissões:** Modelo rígido de controle de acesso baseado em Dono, Grupo e Outros (Leitura, Escrita e Execução).
